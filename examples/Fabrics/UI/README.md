# 🎨 Абстрактная фабрика - UI компоненты

Этот пример демонстрирует паттерн **"Абстрактная фабрика"** для создания семейств UI компонентов для разных операционных систем.

## 🎯 Ключевая особенность абстрактной фабрики

**Абстрактная фабрика создает СЕМЕЙСТВА связанных объектов**, а не отдельные объекты.

### Сравнение с другими фабриками:

- **Простая фабрика**: `ProductFactory::create('book')` → создает ОДИН объект
- **Фабричный метод**: `ServiceFactory->getService()` → создает ОДИН объект (но гибче)
- **Абстрактная фабрика**: `UIFactory->createButton() + createCheckbox()` → создает СЕМЕЙСТВО объектов

## 📁 Структура проекта

```
UI/
├── Interfaces/
│   ├── ButtonInterface.php         # Интерфейс кнопки
│   ├── CheckboxInterface.php       # Интерфейс чекбокса
│   └── UIFactoryInterface.php      # Абстрактная фабрика
├── Windows/
│   ├── WindowsButton.php           # Windows кнопка
│   ├── WindowsCheckbox.php         # Windows чекбокс
│   └── WindowsUIFactory.php        # Фабрика для Windows
├── Mac/
│   ├── MacButton.php               # Mac кнопка
│   ├── MacCheckbox.php             # Mac чекбокс
│   └── MacUIFactory.php            # Фабрика для Mac
├── index.php                       # Демонстрация
└── README.md                       # Этот файл
```

## 🔑 Ключевые концепции

### 1. Семейства объектов
Каждая фабрика создает **полный набор** компонентов для своей платформы:
- Windows: WindowsButton + WindowsCheckbox (в стиле Fluent Design)
- Mac: MacButton + MacCheckbox (в стиле Human Interface Guidelines)

### 2. Совместимость
Все компоненты, созданные одной фабрикой, **совместимы** между собой:
- Единый стиль оформления
- Согласованное поведение
- Одинаковые принципы взаимодействия

### 3. Взаимозаменяемость
Легко переключаться между платформами:
```php
// Заменили одну строчку - изменилась вся платформа!
$factory = new WindowsUIFactory(); // Было
$factory = new MacUIFactory();     // Стало

// Остальной код остается тем же
$button = $factory->createButton('OK');
$checkbox = $factory->createCheckbox('Согласен');
```

## 🚀 Запуск демонстрации

1. Откройте `index.php` в браузере
2. Изучите различия между Windows и Mac компонентами
3. Обратите внимание на семейства объектов

## 💡 Практические примеры использования

### Пример 1: Простое создание
```php
$windowsFactory = new WindowsUIFactory();
$button = $windowsFactory->createButton('Нажми меня');
echo $button->render();
```

### Пример 2: Полиморфизм
```php
function createLoginForm(UIFactoryInterface $factory) {
    return [
        'login' => $factory->createButton('Войти'),
        'remember' => $factory->createCheckbox('Запомнить')
    ];
}

// Работает с любой фабрикой!
$windowsForm = createLoginForm(new WindowsUIFactory());
$macForm = createLoginForm(new MacUIFactory());
```

### Пример 3: Создание семейства
```php
$factory = new WindowsUIFactory();
$components = $factory->createFormComponents([
    'submit_text' => 'Сохранить',
    'agree_checked' => true
]);
```

## ⚖️ Когда использовать абстрактную фабрику?

### ✅ Используйте когда:
- Нужно создавать семейства связанных объектов
- Важна совместимость объектов между собой
- Планируется поддержка нескольких платформ/тем
- Нужна возможность легко переключаться между вариантами

### ❌ Не используйте когда:
- Нужен только один тип объектов (используйте простую фабрику)
- Семейства объектов не связаны между собой
- Система простая и не планируется расширение

## 🔄 Добавление новой платформы

Чтобы добавить Linux UI:

1. Создайте папку `Linux/`
2. Реализуйте `LinuxButton`, `LinuxCheckbox`, `LinuxUIFactory`
3. Все! Существующий код работает без изменений

## 🎯 Основные преимущества

1. **Изоляция семейств**: Windows компоненты не смешиваются с Mac
2. **Легкость расширения**: новая платформа = новая папка
3. **Согласованность**: все компоненты платформы в едином стиле
4. **Тестируемость**: легко создать mock-фабрики для тестов
5. **Гибкость**: переключение платформы = замена одной строчки
